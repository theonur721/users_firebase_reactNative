# Users App

Basit bir kullanıcı yönetim uygulamasıdır.  
Firebase Auth ile kayıt/giriş yapılabilir, Firestore üzerinden kullanıcılar eklenebilir, listelenebilir, güncellenebilir ve silinebilir.

---

## 📌 Özellikler

- 🔐 Firebase Authentication ile kayıt & giriş
- 👤 Kullanıcı ekleme, güncelleme, silme, listeleme
- 📄 Kullanıcı detay sayfası
- 🧳 İş (Job) seçerek kullanıcı ekleme
- 🚪 Logout özelliği
- 🔄 Gerçek zamanlı veri senkronizasyonu

---

## 🛠 Kullanılan Teknolojiler

- React Native
- React 19
- Firebase
- React Navigation
- Iconsax-react-nativejs
- React Native SVG
